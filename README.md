# ok-nte 插件：运通全城（同城派送）

游戏 2026-11 上线的长期活动「运通全城」自动化：打开地图 → 都市闲趣 → 同城派送，
**先结算昨天的单，再按星级派 3 单**，第二天上线自动领结算奖励。

以插件形式安装，宿主 ok-nte 零改动。

## 安装

1. ok-nte 的「插件」页 → **Add from GitHub**
2. 填本仓库地址：`Camellune/ok-nte-city-delivery`
3. 安装 release 里的 `city_delivery_v*.okscript`

> 也可在 Releases 页手动下载 `.okscript`，再用插件页「从 ZIP 添加」选本地文件安装。

安装后「都市闲趣」分组下出现「运通全城」，同时自动追加为「日常」的最后一项。

## 每次运行的流程

1. 按 `M` 打开地图 → 左下角「都市闲趣」→ 卡片「同城派送」
2. **结算阶段**：派遣管理 → 全部结算 → 领奖励 → `ESC` 退出
3. **派遣阶段**（固定 3 单）：
   - 列表整块 OCR，认出全部订单名，按名称框现算行距（列表可上下滚动，不依赖固定坐标）
   - 星带在名称下方现找，按列分段数实心星
   - 跳过已有司机头像 / 倒计时 / 已完成的行
   - 点行 → 核对右侧详情标题是这个单 → 派遣司机 → 圆形加号（游戏自动选最适司机）→ 派遣
   - 见到「派遣中」才算成功
4. 退回游戏主界面

顺序不能反：昨天的单占着派遣名额，不先结算今天派不进去。

## 没有配置项

本插件**不提供任何配置项**，全部按固定规则运行，任务卡片上没有可调参数：

| 行为 | 固定值 |
|---|---|
| 每日派遣次数 | 3（游戏每日上限） |
| 最低星级 | 4 星及以上 |
| 先结算再派遣 | 总是先结算 |
| 都市活力 | 不检查，多少活力都照常派遣 |

## 已知边界

- **结算奖励弹窗**：目前按「按一次 ESC 退出」处理，没有实拍样本。若弹窗需要点按钮才能关，需要补图校准。
- **司机耗尽 / 名额满**：点加号后没弹司机列表就记失败并停止，不硬点。
- **派遣中判定**：点「派遣」后 20 秒内没出现「派遣中」按失败处理，截图留证。
- 仅支持简体中文界面。
