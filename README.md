# ok-nte 插件：运通全城（同城派送）

游戏长期活动「运通全城」自动化：地图 → 都市闲趣 → 同城派送，
**先结算昨天的单，再按星级派今天的单**，第二天上线自动领结算奖励。

以插件形式安装，宿主 ok-nte 零改动。

## 安装

1. ok-nte 的「插件」页 → **Add from GitHub**，填 `Camellune/ok-nte-city-delivery`
2. 或在 Releases 里下载 `.okscript`，用插件页「从 ZIP 添加」选本地文件

装好后任务出现在宿主原有的**「都市闲趣」**分组里（和钓鱼 / 粉爪大劫案 / 排球之星同级），
侧栏不再单独建一页；同时自动追加为「日常」的最后一项。
**需完全退出 ok-nte 再打开**才会加载新版本。

## 每次运行的流程

1. 按 `M` 打开地图 → 左下角「都市闲趣」→ 卡片「同城派送」
2. **先结算**：派遣管理 → 全部结算 → `ESC` 退出（昨天的单占着名额，不结算今天派不进去）
3. **再派遣**（默认 3 单，可在任务卡片调整）：
   - 订单列表整块 OCR，按名称框现算行距，列表滚动过也对得上，不依赖固定坐标
   - 星级按金色像素数，不用模板图
   - 已有司机头像 / 倒计时 / 已完成的行自动跳过
   - 点行 → 核对右侧详情标题 → 派遣司机 → 圆形加号（游戏自动选最适司机）→ 派遣
   - 见到「派遣中」才算成功
4. 退回游戏主界面

## 选择规则

| 项目 | 规则 |
|---|---|
| 每日单数 | 默认 3 单，可在任务卡片「同时派遣数量」调整（1~20）；解锁更多同时派遣位后调大 |
| 星级 | **不设下限**，每次挑当前星级最高的可派单，好单没了就往下顺，把空位填满 |
| 刷新 | 手里最高不到 4 星时点刷新重 roll，刷到 4 星以上就停；刷新键变暗（次数用完）就不点，按最高星级继续派 |
| 特殊订单 | 详情标「特殊订单」或点派遣后提示「需亲自派送」的单直接跳过，换下一单，不消耗当天单数 |
| 都市活力 | 不检查，多少活力都照常派遣 |

## 配置项

任务卡片有一个「同时派遣数量」（默认 3，范围 1~20）。
后期游戏技能解锁更多同时派遣位时调大即可，实际派出量仍受当天订单数与刷新结果限制。
日常子项和独立任务用的是同一份配置。

## 已知边界

- **结算奖励弹窗**按「按一次 ESC」处理，暂无可领奖励的实拍样本。
- 点加号后没弹司机列表（司机耗尽 / 名额满）→ 记失败并停止，不硬点。
- 点「派遣」后 20 秒内没出现「派遣中」→ 记失败、截图留证。
- 刷新后若列表没回来 → 截图并沿用原来的单继续。
- 仅支持简体中文界面。
